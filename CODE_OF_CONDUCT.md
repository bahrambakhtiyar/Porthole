# Code of conduct

Porthole follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). This page is the short version.

## In short

- **Be respectful and patient.**
- **Welcome newcomers.**
- **Keep criticism about the work,** not the person.
- **Don't harass anyone.**
- **Remember that many contributors write in a second language.**

## Reporting

To report unacceptable behaviour, use GitHub's **Report content** option on the comment or issue, or contact the maintainer through the repository's Security tab. Reports are handled privately.
