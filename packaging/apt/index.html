Porthole APT repository

Porthole shares your screen with phones and PCs on your Wi-Fi. They just open a link.

This site holds Porthole's signed APT repository for Ubuntu, Debian and Mint. To install Porthole and get its updates with the rest of your system, run this once in a terminal:

sudo install -d -m 0755 /etc/apt/keyrings && sudo wget -qO /etc/apt/keyrings/porthole.asc https://bahrambakhtiyar.github.io/Porthole/apt/porthole.asc && echo "deb [signed-by=/etc/apt/keyrings/porthole.asc] https://bahrambakhtiyar.github.io/Porthole/apt stable main" | sudo tee /etc/apt/sources.list.d/porthole.list && sudo apt update && sudo apt install porthole

Other ways to install, and how to use Porthole: github.com/bahrambakhtiyar/Porthole.
